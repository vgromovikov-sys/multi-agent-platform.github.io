# КЕРН — прототип мультиагентной платформы

Интерактивный прототип рабочего места для корпоративных AI-агентов. В нём можно выбрать агента, изучить его входные данные, пройти демонстрационный сценарий и посмотреть, как пользователь получает результат.

**[Открыть демо на GitHub Pages](https://vgromovikov-sys.github.io/multi-agent-platform.github.io/)** · [Пример интерактивной презентации](https://vgromovikov-sys.github.io/multi-agent-platform.github.io/investcom-severny.html)

## Что показать на демо

| Сценарий | Куда перейти |
| --- | --- |
| Работа с результатом агента | В **Истории** откройте «Протокол: совещание по ГТМ, куст 14». В ответе показаны резолюция, поручения и риски. |
| Аналитика для инвесткомитета | В **Истории** откройте сценарии по ЛУ «Северный». В табличном сценарии сравните NPV и IRR, а в сценарии генерации презентации откройте интерактивные слайды. |
| Настройка агента | В разделе **Агенты** откройте карточку агента и посмотрите модель, коллекции и форматы входных и выходных данных. В конструкторе можно редактировать схему и запустить пробный сценарий. |
| Корпоративные инструменты | В **Коллекциях** посмотрите источники знаний, в **Корпоративной почте** — примеры приоритизации писем, а в **Администрировании** — демонстрационную статистику и настройки. |

Демо работает в браузере на встроенных примерах. Ответы агентов, показатели, интеграции и вложения без ссылки имитируются. Интерактивная презентация открывается отдельно и из чата. Для показа удобнее использовать полноразмерное окно браузера.

## Локальный запуск

Из корня репозитория запустите любой статический HTTP-сервер. Например, с Python 3:

```bash
python -m http.server 8000 --bind 127.0.0.1
```

Затем откройте [http://127.0.0.1:8000/](http://127.0.0.1:8000/). React и ReactDOM поставляются вместе с прототипом. При недоступности Google Fonts браузер использует системные шрифты.

## Публикация

В **Settings → Pages** выберите **Deploy from a branch**, ветку **main** и папку **/ (root)**. Обновления ветки `main` запускают публикацию. Сайт состоит из статических файлов и не требует отдельной сборки.
